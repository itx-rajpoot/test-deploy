PORTFOLIO WEBSITE
=================

Features:
- Responsive portfolio
- Header and footer
- About section
- Experience section
- Skills with percentage scales
- Projects section
- Contact form
- Admin dashboard
- LocalStorage data persistence
- External CSS and JavaScript
- No backend required

HOW TO RUN
----------
1. Open the "portfolio" folder.
2. Double-click index.html, OR use VS Code Live Server.
3. Open admin.html to manage the portfolio.
4. Changes made in Admin are saved in browser LocalStorage.
5. Refresh index.html to see updated data.

IMPORTANT
---------
LocalStorage belongs to the browser and computer where the site is opened.
This is a frontend demo/admin interface, not a secure production admin system.
For real authentication and multi-user data, a backend/database should be added.
